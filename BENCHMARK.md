# Benchmarks

Per-format CPU time and peak RAM against Bio-Formats and bioformats-rs
are in `tests/expected/<format>_bench.md` (written by
`tests/scripts/oracle.py`) and summarised in the README. This file records
the larger runs.

## AVI (2026-11-04, Intel Core Ultra 9 185H, Bio-Formats 8.5.0, bioformats-rs 0.1.8)

1000 frames of 1024 x 1024 (generated by `make_avi_samples.py --bench`),
median of 3 fresh processes, CPU s / peak RAM MiB. The reference readers
read only 500 frames of the OpenDML file (first RIFF chunk).

| Input | scopeio | Bio-Formats | bioformats-rs |
|---|---:|---:|---:|
| raw 8-bit OpenDML, 1.0 GB, all frames | 0.37 s / 5.7 | 8.75 s / 906 (500 frames) | 0.86 s / 1011 (500 frames) |
| raw 8-bit, 512 x 512 region of every frame | 0.18 s / 4.7 | 4.84 s / 670 (500 frames) | – |
| Motion JPEG 4:2:0, 65 MB, all frames | 2.92 s / 16.9 | 12.71 s / 739 | 8.73 s / 6019 |
| Motion JPEG, 512 x 512 region of every frame | 2.82 s / 14.8 | 11.96 s / 827 | – |

scopeio reads uncompressed frames row by row from the file, so RAM stays
at a few MiB independent of the file size; Motion JPEG frames are decoded
whole (one frame in memory, cached). Reference times include writing the
pixels to ICS and, for Bio-Formats, JVM start-up.

Full table: `tests/expected/avi_bench.md`.
