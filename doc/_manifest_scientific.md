# Format documentation manifest: scientific, medical, EM and generic n-D formats

Collected 2026-10-24 for the scopeio clean-room reader. No Bio-Formats material (source, javadoc, or
format pages) was opened or downloaded. No reader/library source code was downloaded. The only C
headers included are the official NIfTI format definitions.

Total size of this group: about 47 MB (60 files).
